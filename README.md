# Hotkey Launcher for Windows

Launch or minimize apps and folders with global shortcuts, and expand short triggers into saved text.

[Download the latest Windows MSI](https://github.com/brainok/hotkey-launcher-win-release/releases/latest/download/HotkeyLauncher.msi)

[Download the standalone EXE](https://github.com/brainok/hotkey-launcher-win-release/releases/latest/download/HotkeyLauncher.exe) to run without MSI installation. It does not create a Start menu shortcut; use the MSI for a standard install and future upgrades.

Requires 64-bit Windows. Run the MSI manually to install or upgrade, then open Hotkey Launcher from the Start menu. Existing user settings are retained. The app does not automatically download or install updates.

The MSI has a valid Authenticode code signature issued by SSL.com to HYO SUK NAM. The standalone EXE is provided separately.
